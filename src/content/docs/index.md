## About these docs

Open MMORPG continues the MMORPG Kit by Ittipon Teerapruettikulchai (insthync), which he
released as open source, by way of the MmoKitCE project by Denarii Games. These pages are
written for Open MMORPG and checked against its code. Found a mistake? Every page has an
**Edit page** link at the bottom. Corrections are welcome.

Open MMORPG is guided by the **Three S's**: **Scalability**, **Stability**, and **Security**. To maintain a lean, high-performance core engine that is easy to update, optional or specialized features are distributed as modular **Addons**.

---

## 1. Opening the Addon Manager

Open MMORPG includes an in-editor package management window:

1. In the Unity top menu, open **Open MMORPG → Develop → Addon Manager**.
2. The window lists all official and community addons available for your installed version of the kit.

---

## 2. Managing Addons

From the Addon Manager interface, you can:

* **Browse Addons**: Read descriptions, requirements, and feature notes for each module.
* **Install with One Click**: Download and import addons directly into your project.
* **Check for Updates**: See which addons have newer releases available and update them in place.
* **Uninstall**: Remove unused addons to keep your project size small and compile times fast.

---

## 3. Popular Official Addons

| Addon | Purpose |
| :--- | :--- |
| **Shooter Extensions** | Adds advanced gun mechanics, projectile ballistics, weapon recoil, iron-sights zooming, and crosshair reticles. |
| **Top-Down Controller** | Adds classic Diablo-style click-to-move navigation and mouse cursor aiming. |
| **2D AI** | Integrates A* Pathfinding for 2D monsters and enemies. |
| **UMA Integration** | Integrates Universal Multipurpose Avatar (UMA) for high-fidelity procedural character generation and clothing swapping. |
| **Google Play & Facebook Auth** | Adds mobile OAuth social login providers to the Login Server. |
